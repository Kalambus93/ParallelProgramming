# Параллельное программирование

Исследование и результаты лабораторных работ:

- [**Лабораторная работа 1**](labs/lab1/README.md) — последовательная версия.
-  [**Лабораторная работа 2**](labs/lab2/README.md) — OpenMP.

---

Тема репозитория - распараллеливание вычислительной задачи. В качестве задачи представлена операция перемножения двух матриц. Используемые языки программирования: C/C++, Python.

Исследование параллельного программирования проходит в несколько этапов:
* Лабораторная работа №1 заключается в получении  данных о производительности последовательного вычисления произведения квадратных матриц (измерение времени в сек без распараллеливания)
* В лабораторной работе №2 необходимо использовать стандарт распараллеливания OpenMP
* В лабораторной работе №3 используется MPI. Лабораторная работа запускается на суперкомпьютере.
* Лабораторная работа №4 выполняется с использованием CUDA ядер.

---
## Требования к окружению

- Компилятор с поддержкой C++23 (GCC 14+, Clang 18+)
- CMake 3.20+
- Python 3.10+ и NumPy (для верификации)
